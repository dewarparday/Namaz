# Prayer Tasks Flutter App

Offline Android Prayer Tasks tracker.

## Features
- Fajr, Zuhr, Asr, Maghrib, Isha
- Daily completion tracking
- Completion percentage
- Date selection
- Prayer history
- Qaza counter
- Local/offline storage
- Material 3 UI

## Build
Install Flutter SDK and Android Studio.

Then run:

```bash
flutter pub get
flutter run
```

To generate an APK:

```bash
flutter build apk --release
```

APK will be created under:
`build/app/outputs/flutter-apk/app-release.apk`
